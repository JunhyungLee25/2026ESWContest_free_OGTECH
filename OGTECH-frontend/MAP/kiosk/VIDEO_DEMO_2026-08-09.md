## 장면 키와 촬영 순서

브라우저를 한 번 클릭한 뒤 숫자키를 누른다. `A`는 베이스캠프 등록부터 야간 모드까지 한 번에
자동 재생한다. `Space`는 다음 장면, `R`은 처음, `B`는 현재 장면의 음성 재생, `T`는
현재 일조 잔여 안내 재생, `N`은 야간 모드다. `D`는 경로 이탈 경고 시연으로, 현재 위치를 활성
경로에서 45 m 밀어내 배너를 띄우고 다시 누르면 복귀한다(자동 재생은 멈추지 않는다). 자동 재생 중
숫자·조작 키·터치 입력을 하면 자동 재생을 멈추고 해당 수동 조작으로 전환한다.

| 키 | 화면 | 촬영·편집 포인트 |
|---:|---|---|
| `1` | 공학관 뒤 BASE CAMP 시작 | `베이스캠프` 버튼을 누르면 “베이스캠프가 등록되었습니다.” 표시 |
| `2` | 음성 요청 → 일감호 자동 설정 | “가장 가까운 지점에 호수가 있습니다. 이곳을 목적지로 지정할까요?” 뒤 3초 쉬고 “네, 목적지로 설정되었습니다.” 재생 |
| `3` | 일감호 방향 이동 | 합성 마커가 약 2분 45초 이동. 종료 시 `4`로 자동 전환 |
| `4` | 일감호 도착 | “목적지에 도착하였습니다.” 화면·음성 동시 출력 |
| `5` | 일조 잔여 경고 | 당일 일몰과 현재 서울 시각의 차이를 `nn분 남음`으로 표시하고 같은 `nn`을 넣은 “해 지기까지 nn분 남았습니다. 귀환 권고 시각과 Base Camp 경로를 확인하세요.” 음성 재생 |
| `6` | BASE CAMP 복귀 재생 | 돌아가는 실물 이동 컷과 교차 편집 |
| `7` | BASE CAMP 도착 | “Base Camp에 도착하였습니다.” 화면·음성 동시 출력 |

### 원테이크 자동 재생

`A`를 한 번 누르면 아래 순서가 약 6분 동안 자동 실행된다. 장면 3과 6은 고정 대기 시간이
아니라 지도 경로 길이와 일반 보행 연출 속도 1.4 m/s `[추정]`로 마커가 도착할 때까지 재생한다.

1. BASE CAMP 등록 문구 표시
2. 일감호 목적지·경로 설정 음성
3. 일감호까지 이동 → 목적지 도착 화면·음성
4. 현재 일조 잔여 분 경고 음성
5. BASE CAMP 복귀 경로 문구 → 복귀 이동 → BASE CAMP 도착 화면·음성
6. 야간 모드 활성화 문구

Jetson에서 SSH로 시작할 때는 `video.html`을 먼저 열고 다음을 실행한다.

```bash
bash /home/kit/00_TEST/0809_test/auto_demo_ssh.sh
```

`auto_demo_ssh.sh`는 현재 화면에 `A` 키를 보내므로 Firefox 키오스크 창이 앞에 있어야 한다.
전체 파일을 `kiosk` 폴더째 옮긴 경우에는 해당 하위 경로를 사용한다.

경로 정보 카드에는 이동 대상(`목적지` 또는 `BASE CAMP`), 방위각, 남은 거리와 함께 KST 예상
도착 시각과 남은 분을 표시한다. 두 값은 남은 경로 거리와 1.4 m/s 보행 속도로 코드가 계산한다.

상단 첫 칸에는 `대한민국 · 서울 광진구`의 날짜와 KST 시각을 표시하고, 세 번째 칸에는 현재
위도·경도를 같은 크기와 색으로 표시한다. 네 번째 칸에는 `30.0°C (86.0°F)`와 `55% RH`를 같은
크기(20px)로 표시한다. 온도 색은 30°C 초과 적색, 20~30°C 황색, 20°C 이하 녹색이고 습도는 하늘색이다
`[출처: video_styles.css, video_app.js temperatureLevel]`. 다섯 번째 칸에는 `CO 농도`와 0 ppm만
표시한다(모의 표시 배지는 2026-08-29 제거). CO 센서 값은 CO만 감시하며 산소 부족·CO₂·메탄·황화수소 등
다른 위험 가스의 안전을 보증하지 않는다. 지도 위의 긴 장소명과 `OFFLINE` 배지는 제거했다.

경로 이탈 경고: 활성 경로(목적지 또는 BASE CAMP 경로)에서 현재 위치가 30 m(`navigation_service`
`TRAIL_THRESHOLD_M` 기본값과 동일) 넘게 벗어나면 지도 상단에 적색 배너
`경로 이탈 · nn m · 현재 위치와 경로를 확인하세요`를 표시하고 복귀하면 지운다. 이탈 거리는 현재 위치에서
경로 선분까지의 최단 거리를 코드가 계산한다. 일조 경고와 같이 뜨면 그 아래에 쌓이고, 활성 경로가 없으면
판정하지 않는다.

이동 재생은 실제 GPS 트랙이 아니라 영상용 합성 궤적이다. 실제 좌표가 보이는 STM32 시리얼 화면은
영상에 넣지 않는다.

### 화면 아래 버튼

| 버튼 | 동작 |
|---|---|
| `목적지` | 지도 터치 지정 모드. 지도에서 원하는 지점을 누르면 보행망에 스냅하고 코드가 경로 계산 |
| `체크포인트` | 누른 순간의 현재 위치를 화면 메모리에 저장하고 지도에 표시 |
| `베이스캠프` | 장면 1에서는 현재 위치 등록, 이후에는 등록 지점까지 복귀 경로 표시 |
| `야간 모드` | 적색 단색 화면으로 전환하고 활성화 문구 표시 |

숫자 `2`는 영상에서 LLM 음성 질의가 검수 POI `일감호 주변 휴식 지점`을 고른 결과를
자동 재생한다. 하단 `목적지` 버튼과는 독립된 흐름이다. 좌표·경로는 LLM이 아닌 지도 코드가 계산한다.

### 위치와 서울 시간

`LOCATION · TIME`은 네트워크 API가 아니라 Jetson 시스템 시각을 `Asia/Seoul`로 변환해 갱신한다.
인터넷이 없어도 동작하지만 시스템 시각 자체가 맞아야 한다. 촬영 전 다음을 확인한다.

```bash
sudo timedatectl set-timezone Asia/Seoul
timedatectl
```

제품 경로의 DS3231은 출고·정비 때 로컬 직렬 `SET RTC UTC YYYY-MM-DDTHH:MM:SSZ`로만 설정한다.
Jetson 시스템 시각을 RTC에 자동 복사하지 않는다. 실제 제품 화면은 유효하고 신선한 STM32 RTC
telemetry를 우선 사용하며, 이 영상 전용 페이지의 시계만 Jetson 시스템 시각으로 연출한다.
온습도는 이번 촬영 화면에서 `30.0°C / 55% RH` 고정 시나리오 값이다.

DAYLIGHT는 건국대학교 현재 좌표에서 NOAA 공개 근사식과 `MAP/solar_service.py`의 동일 절차로
당일 일몰을 오프라인 계산하고, `당일 일몰 - 현재 서울 시각`을 `n시간 n분 남음`으로 매초 표시한다
`[출처: 코드 계산]`. 장면 5에서는 같은 분 값을 화면 경고와 브라우저 한국어 음성 합성에 함께 넣는다.
일몰 뒤에는 경과 시간을 `n분 초과`로 표시하고 “일몰 시간이 지났습니다. 귀환 권고 시각과
베이스캠프 경로를 확인하세요.”를 출력한다. 계속 진행·철수 결정은 장치가 대신하지 않는다.
브라우저에 한국어 음성 합성기가 없으면 경고를 화면에만 표시한다. 과거 촬영용
`daylight_detail.wav`는 직접 행동을 지시하는 문구를 담고 있어 현재 UI에서 참조·재생하지 않으며 MAP
서버의 정적 파일 목록에서도 제외한다.

## STM32만 들고 이동할 때 실제 GPS 로깅 여부

### 현재 가능한 것

- STM32와 Air530에 전원이 들어오면 Jetson이 없어도 Air530 NMEA를 계속 수신한다 `[출처: 펌웨어]`.
- 유효한 fix가 생기면 최신 실제 위도·경도와 위성 수를 STM32 RAM에 보관한다 `[출처: 펌웨어]`.
- USB 또는 USART2에 기록 장치가 연결돼 있으면 1초 JSON 텔레메트리를 외부에서 저장할 수 있다
  `[출처: 펌웨어]`.
- Jetson이 꺼져도 CO 경보 출력은 STM32에서 계속 동작한다 `[출처: 펌웨어]`.

### 현재 불가능한 것

- STM32만 배낭 안에 넣고 외부 기록 장치 없이 이동하면 **전체 GPS 트랙은 저장되지 않는다**.
- 현재 펌웨어는 마지막 fix만 RAM에 두므로 전원이 꺼지면 좌표가 사라진다.
- 따라서 오늘 이동 장면을 실제 GPS 로그 증명 장면으로 쓰면 안 된다.

### 다음 주 구현 범위

다음 주 실제 통합 작업에서는 저장 매체를 먼저 확정한다.

1. 권장: microSD에 시간·위도·경도·위성 수·원본 fix 상태를 CRC와 함께 순차 저장
2. 대안: STM32 내부 플래시 예약 섹터에 순환 로그. 플래시 마모·전원 차단 복구·링커 영역 분리를 함께 구현
3. DS3231 시각을 붙여 Jetson이 꺼져 있어도 로그 시각을 유지
4. Jetson 재연결 시 새 레코드만 전송하고 ACK 뒤 읽음 위치를 갱신
5. 실제 개인 GPS 트랙은 Git에 커밋하지 않고 `runtime/`에만 보관

실외에서는 Air530 안테나가 하늘을 볼 수 있게 하고, 출발 전에 유효 fix와 위성 수를 직렬 출력으로 한 번
확인한다. 하드웨어 결선 실측이 아직 끝나지 않았으므로 오늘 결과는 안전 장치 검증으로 간주하지 않는다.
