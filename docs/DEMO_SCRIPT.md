# 3분 데모 스크립트

데모 영상은 스크린샷만이 아니라 실제 임베디드 시스템을 보여줘야 합니다.

## 목표 실행 시간

- 최대 길이: 3분.
- 최소 품질: 720p.
- 실제 장치, 야외 촬영, 센서 동작, 안전 대체 경로를 보여줘야 합니다.

## 스토리보드

| 시간 | 장면 | 메시지 |
| --- | --- | --- |
| 0:00 ~ 0:15 | 배낭에 장착된 장치 · 야외 | 인터넷 없이 작동하는 오지 생존 보조 장치 |
| 0:15 ~ 0:40 | 오프라인 지도에 현재 위치 표시 | 통신이 끊긴 곳에서 지도와 좌표가 살아 있음. 정확도(±m)를 같이 표시 |
| 0:40 ~ 1:05 | **트레일 이탈 → 진동·음성 경고 → 위치 로그 역추적** | 길을 벗어난 순간 알려 주고, 되돌아갈 방위와 거리를 제시 |
| 1:05 ~ 1:30 | **남은 일조 시간 카운트다운 → 적색 경고** | 되돌아설 시점을 장치가 먼저 말함. 전부 오프라인 계산 |
| 1:30 ~ 2:00 | **Jetson 전원을 뽑은 상태에서 CO 경보** | 사용자가 자고 있어도, 메인 보드가 꺼져 있어도 감시는 계속됨 |
| 2:00 ~ 2:25 | 음성 질문 → 검수 카드 → 음성 응답 | 마이크로 묻고 2초 안에 답. LLM은 절차를 생성하지 않음 |
| 2:25 ~ 2:45 | LLM 강제 종료 → 고정 카드 폴백 | 모델이 죽어도 장치는 계속 동작 |
| 2:45 ~ 3:00 | 전력 계기 · 안전 경계 고지 | 14일 운용 근거, "구조 요청 수단이 아님" 명시, GitHub URL |

## 필수 촬영 장면

- 배낭 장착 상태 와이드 샷 (야외, 실제 지형).
- 화면을 꺼내 드는 동작과 글랜서블 4개 클로즈업.
- **장갑 낀 손으로 물리 버튼을 누르는 장면.**
- **Jetson 전원 케이블을 뽑고 CO 경보가 울리는 연속 촬영** — 이 장면이 이 작품의 핵심입니다.
- GPS 미수신 상태가 **회색으로** 표시되는 장면 (숨기지 않습니다).
- 실패 장면을 편집으로 숨기지 않는 하나의 연속 흐름.
- 프로젝트 이름과 GitHub URL이 보이는 마지막 장면.

## 촬영 금지

- 시뮬레이션 값을 실측처럼 보이게 하는 편집. **`DEMO` 배지가 화면에 있으면 그대로 찍습니다.**
- 검증하지 않은 기능(14일 연속 운용 등)을 실측인 것처럼 보여 주는 장면.
- "구조 요청" 또는 "119 자동 신고"로 오해할 수 있는 연출.
