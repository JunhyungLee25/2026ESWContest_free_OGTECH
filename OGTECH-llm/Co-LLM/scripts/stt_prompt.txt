#   버너 -> 번호   ·   텐트 -> 헨트/헤드피언   ·   목적지 -> 목격체
#   '버너' 단독은 저 SNR 에서 실패하므로 '가스'/'불'/'켜'를 다른 문장에 분산했습니다.

# 105음절이라 상한에 닿을 수 있어(추정 154~227 tok), 잘려도 살아남아야 하는
# 어휘를 아래쪽에 배치했습니다. 판정 ①(#13 버너·CO / #15·#16 refuse) 순서 그대로입니다.
#   앞줄  = 경로·항법 어휘. 잘려도 시연이 안 죽습니다
#   뒷줄  = refuse(버섯·열매) -> 가스 -> 버너 -> 텐트
# 마지막 줄이 가장 잘 새어 나오므로, 새어도 피해가 가장 작은 '텐트'를 맨 끝에 뒀습니다.

#   남기고 뺐습니다. '배낭 무겁다'도 뺐습니다 — 21문장 어디에도 게이트 키워드가 없습니다.
