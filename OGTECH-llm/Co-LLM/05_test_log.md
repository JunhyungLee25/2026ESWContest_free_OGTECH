## STT 정확도 — 발화 6개

같은 문장을 각 엔진으로 읽히고 그대로 옮겨 적으세요. 오타까지 그대로 적어야 판단이 됩니다.

| # | 실제 발화 | 받아쓴 텍스트 | 핵심어 맞음? |
|---|---|---|---|
| 1 | 여기가 어디야 | | O / X |
| 2 | 해 지기 전에 돌아갈 수 있어 | | O / X |
| 3 | 오늘 밤 얼마나 추워져 | | O / X |
| 4 | 이 물 마셔도 돼 | | O / X |
| 5 | 텐트 어디에 쳐야 돼 | | O / X |
| 6 | 이 버섯 먹어도 돼 | | O / X |

> 6번은 안전 계약 6번의 `refuse` 게이트 대상입니다. 지금은 **받아쓰기만** 정확하면 됩니다.
> 실제 제품에서는 이 문장이 모델에 도달하기 전에 키워드 게이트가 차단합니다.

```
STT 엔진:
6개 중 핵심어 정답:        / 6
오인식 사례 (실제 -> 받아쓴 것):
마이크 거리:               cm
주변 소음:                 조용함 / 보통 / 시끄러움
```
