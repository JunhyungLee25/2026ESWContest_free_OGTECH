## 0. 분류 원칙

위험을 "무섭기 순"이 아니라 **`발생빈도 × 치명도 × 우리가 개입 가능한가`** 로 정렬합니다.
곰·독사처럼 극적이지만 드문 위험에 자원을 쓰면 안 됩니다.

**개입 가능성 등급**
- ◎ **직접 차단** — 장치가 위험 자체를 막거나 감지함
- ○ **판단 보조** — 사용자가 옳은 결정을 하도록 재료를 제공
- △ **정보 제공만** — 사후 참고
- ✗ **개입 불가** — 정직하게 못 한다고 적을 것

## 2. 위험별 상세

### A. 길 잃음 / 조난 — **최우선**

**초보자가 길을 잃는 실제 메커니즘**

| 단계 | 무슨 일이 일어나나 | 근거 |
|---|---|---|
| 1 | **분기점에서 잘못된 갈래로 진입.** 정규 등산로 / 미정비로 / 짐승길 / 사람이 낸 샛길 / 계곡선의 구분 실패 | **길 잃음의 56%가 분기점에서 발생** |
| 2 | 잘못됨을 인지하지만 **"조금만 더 가면 나오겠지"** 로 진행 | Largay 사례 |
| 3 | **신호를 찾아 높은 곳으로 이동** → 수색 예상 범위에서 이탈 | Largay 사례 |
| 4 | 방향감각 상실. 원형 배회(circling) 시작 | 조난자 행동 연구 |
| 5 | 체력·수분 소진 → 판단력 저하 → 회복 불가 | |

**초보자 고유의 증폭 요인**

| 요인 | 설명 |
|---|---|
| **GPS 과신** | 도시에서 내비게이션으로만 다녀 스스로 길 찾은 경험이 없음 `[출처]` |
| **구조 낙관** | "국립공원이니까 911(119) 한 통이면 온다"고 믿음 `[출처]` |
| **종이 지도 독도 불가** | 등고선·방위 개념 없음 |
| **단체 산행의 역설** | 통계상 단체에서 낙오가 더 자주 발생. **낙오자 대부분이 독립 항법 능력 없음** `[출처]` |
| 배터리 관리 부재 | 폰이 유일한 지도인데 방전됨 |

**우리 장치의 대응 (◎)**

| 기능 | 어느 단계를 차단하나 |
|---|---|
| 트레일 폴리라인 이탈 경고 (진동 + 음성) | **1단계** — 가장 값싸고 효과 큼 |
| 분기점 사전 마킹 + 접근 시 알림 | **1단계** |
| GPS 자동 위치 로깅 + 위치 로그 역추적 | **2·3단계** — Largay가 살 수 있었던 경로 |
| "멈추세요(STOP)" 고정 카드 | **3·4단계** |
| 마지막 확정 좌표 상시 표시 | 전 단계 |

> **주의**: 4단계 이후는 이 장치의 범위를 벗어납니다. 사용자는 별도의 구조 요청 수단을 지참해야 합니다.

### B. 야간 갇힘 (benightment) — **가장 만들기 쉬운 P0**

| 항목 | 값 |
|---|---|
| 미 NPS 국립공원 SAR 중 야간 발생 | **22%** `[출처]` |
| 주된 원인 | 계획에 없던 야간 복귀 |
| 급증 시기 | **봄·가을 (일몰이 예상보다 이름)** |
| 일몰 후 여유 | 시민박명 약 30분. **숲·계곡은 훨씬 짧음** |

**초보자의 실패 논리**
1. 정상까지 걸린 시간만 보고 "돌아갈 때도 같겠지"라 가정 → **하산은 피로·어둠 때문에 더 걸림**
2. 헤드램프 미지참 (10 essentials 중 가장 흔히 빠지는 항목)
3. 회귀 시각(turnaround time) 개념 자체를 모름

**우리 장치의 대응 (◎ — 결정론적 계산)**

```
남은 일조시간 = 시민박명 종료시각 − 현재시각        [NOAA/Meeus, 오프라인 순수 계산]
필요 시간     = 잔여 거리 ÷ 최근 30분 실측 이동속도   [GPS 트랙에서 계산]

if 필요시간 > 남은 일조시간 × 0.8:
    → 적색 경고 + 음성: "지금 돌아서야 합니다"
```

**이 계산에는 LLM이 필요 없습니다.** 코드가 합니다. LLM은 결과를 문장으로 읽어 줄 뿐입니다.
→ 안전 계약 §5-1 준수.

### C. 저체온증 / 노출

**초보자가 가장 크게 오해하는 위험입니다.**

| 오해 | 사실 |
|---|---|
| "영하일 때만 걸린다" | **4~7°C(40~45°F)에서 젖은 옷 + 바람이면 매 시즌 사망자 발생** `[출처]` |
| "겨울 산행만 위험" | **토무라우시는 7월 사고, 8명 사망** |
| "추우면 알아차린다" | 저체온증은 **판단력을 먼저 무너뜨립니다.** 알아차릴 능력이 사라짐 |

**3대 가중 요인: 젖음(wet) · 바람(wind) · 탈진(exhaustion)**
"추운 공기가 아니라 젖음이 등산객을 죽인다."

**국내 패턴**: 설악산 사망 사례 2건 모두 **하산 중**. 땀에 젖은 상태 + 활동량 감소 + 기온 하강의 3중 조합.

**우리 장치의 대응 (○ — 판단 보조까지만)**

| 가능 | 불가능 |
|---|---|
| 기온·습도·기압 실측 표시 | **체온 측정** (피부 온도 ≠ 심부 온도, 증명 불가) |
| 풍속 추정 (기압 변화율 기반, 추정 배지 필수) | **저체온증 진단** — 안전 계약 §6 위반 |
| "젖은 옷 교체" 고정 카드 (하산 구간 진입 시) | 처치 지시 |
| 위험 조건 조합 경고 (기온 < 10°C + 습도 > 85%) | |

> **주의**: 웨어러블 체온 센서를 붙이고 싶어질 겁니다. **하지 마세요.**
> 구 도메인에서 `vision.py`를 삭제한 이유(증명 불가 + 위험)와 정확히 같습니다.

### D. 수면 중 위험 — **요구 3.2에 대한 답**

사용자가 **의식이 없는 8시간**. 사람이 스스로 감시할 수 없으므로 **기계가 필요한 유일한 구간**입니다.

| 위험 | 근거 | 개입 |
|---|---|---|
| **일산화탄소 중독** | 미국 텐트/캠퍼 내 CO 사망 **연평균 30명** (1990~94). 조지아 1999년 일가족 4명 사망 | ◎ **CO 센서 + 부저.** 원가 5천~2만 원 |
| **저체온증 진행** | 젖은 옷으로 취침 → 토무라우시 2일차 패턴 | ○ 취침 전 체크리스트 + 텐트 내 기온 감시 |
| **야영지 물리 위험** | 고사목(widowmaker), 급류 범람, 찬 공기 정체 | ○ 야영지 선정 체크카드 (설치 전) |
| **급격한 기상 변화** | 야간 강수·강풍 | ○ 기압 급강하 감시 → 알림 |
| **방향감각 상실** | 야간 용변 후 텐트 미복귀 (Largay 유형) | ◎ **텐트 위치 원터치 저장 + 복귀 유도** |

**권고 구현 (우선순위 순)**

1. **CO 경보** — 가장 확실. STM32 상시 전원 계층에 물림. Jetson이 꺼져 있어도 동작해야 함.
2. **텐트 앵커(tent anchor)** — 버튼 한 번으로 현 좌표 저장. 이후 "텐트까지 방위 XXX°, 거리 XXm".
   Largay 사고 유형을 직접 차단하고, **구현이 3시간이면 끝납니다.**
3. **야간 감시 모드** — 화면 소등, STM32만 깨어서 CO·기온·기압 로깅. 임계 초과 시 Jetson 기동 + 음성 경보.
4. **취침 전 체크카드** — 고정 카드 5줄: 고사목 / 저지대 / 텐트 내 화기 / 젖은 옷 / 텐트 앵커 저장.

> **이 4개가 "수면 중 안전 기능이 딱히 생각 안 난다"에 대한 답입니다.**
> 특히 1번과 2번은 심사위원에게 **"사람이 못 하는 걸 기계가 한다"** 를 증명하는 기능입니다.

### E. 탈수 · 열손상 (P1)

| 기준 | 값 |
|---|---|
| 중강도 산행 수분 소요 | **시간당 약 0.5 L** `[출처]` |
| 일일 권장 | 1~2 L, 더위·급경사에서 **3~4 L 이상** |
| 휴대 기준 | 2시간당 1 L |

대응(○): 경과 시간 × 활동 강도 기반 **수분 섭취 리마인더**, 오프라인 지도에 **수원 레이어** 표시.
금지: 특정 수원의 음용 가능 여부 판정.

---

### F. 탈진 · 지병 발현 (P1)

국내 산악사고 원인 **3위 (17%, 7,593건)**. 심정지·심혈관 사건 포함.

대응(△): 사실상 개입 불가. **다만 여기가 구 의료 도메인 자산이 되살아나는 지점입니다.**
검수된 응급처치 고정 카드를 **오프라인 참조 자료로 유지**하면, 도메인을 바꿔도 기존 작업이 버려지지 않습니다.
---

### G. 실족 · 추락 (P1, 사후 대응만)

국내 원인 **1위 (31%, 13,686건)**.

**정직한 판정: 우리는 실족을 막을 수 없습니다.** 이걸 막겠다고 주장하면 심사위원에게 즉시 깨집니다.

가능한 사후 대응(○):
- **낙상 감지** (IMU 가속도) → 일정 시간 무응답 시 마지막 좌표 고정 + 경보음. *(오탐률 관리 필요)*
- 사고 지점 좌표 기록 → 나중에 구조대에 제공

## 3. LLM 시나리오 라벨 집합 (제안)

기존 9개 의료 라벨을 폐기하고 아래로 교체합니다.
**라벨은 "우리가 답할 수 있는 것"에만 존재해야 합니다.** 답 못 하는 주제는 라벨을 만들지 않습니다.

```
lost            길을 잃음 · 현재 위치 모름
route           경로·거리·방향 질문
daylight        시간·일몰·회귀 판단
weather         날씨·기온·기압
shelter         야영지 선정·비박·텐트
warmth          추위·젖음·체온 관리
water           수분·수원·정수
food            식량·배급 (※ 야생 식용 판정은 refuse로 강제 분기)
sleep_safety    취침 안전·CO·야간
injury          부상 (고정 카드로만 응답)
wildlife        동물·벌·뱀
gear            장비·배터리·장치 사용법
refuse          금지 질문 (식용 판정, 진단, 구조 필요 여부)
unknown         분류 실패
```

**14개 라벨.** 기존 9개보다 늘었으므로 [05](05_llm_harness_redesign.md)에서 분류 정확도를 재측정해야 합니다.

`refuse`를 **별도 라벨로 둔 것이 핵심**입니다. 금지 질문을 `unknown`으로 흘리면
모델이 답을 시도할 여지가 남습니다. 명시 라벨로 잡아 고정 거부 카드로 보냅니다.
