# 06. 전력 예산 — "2주~1달"이 물리적으로 가능한가

요구 3.5에 대한 답입니다.
질문 원문: *"1. 발전기를 넣을지 / 2. 태양광을 이용할지 / 3. 2주~1달 버틸 수 있도록 하는 큰 배터리 장착하기(어느정도 크기와 용량이 필요할지)"*

**이 문서가 docs2 전체에서 가장 중요합니다.** 다른 모든 기능이 여기서 결정됩니다.

---

## 1. 결론 먼저

| 질문 | 답 |
|---|---|
| 상시 구동으로 2주 가능? | **❌ 불가능.** 약 4,200 Wh 필요 → 배터리만 **30~45 kg** |
| 상시 구동으로 1달 가능? | **❌ 논외.** 9,000 Wh, 70~90 kg |
| 그럼 어떻게 하나 | **듀티 사이클링.** STM32 상시 + Jetson 온디맨드 → 14일 **약 250 Wh** |
| 250 Wh 배터리 무게 | **Li-ion(NMC) 1.3~1.7 kg** / **LiFePO4 2.5~3.5 kg** |
| 발전기 | **❌ 넣지 마세요.** 수동 크랭크 1시간 = 5~10 Wh. 필요량의 4% |
| 태양광 | **⭕ 보조로만.** 개활지 유효, **숲 아래 80% 이상 감소** |

**한 줄: 배터리를 키워서 푸는 문제가 아니라, Jetson을 꺼서 푸는 문제입니다.**

## 3. "2주 상시 구동"이 왜 불가능한가

```
가정: S3(화면 ON, Jetson 유휴) 상태로 14일 연속

  13 W × 24 h × 14일 = 4,368 Wh

배터리 무게 (셀 수준 에너지 밀도)
  Li-ion NMC   : 150~200 Wh/kg  →  22 ~ 29 kg  (팩 수준이면 30~40 kg)
  LiFePO4      :  90~160 Wh/kg  →  27 ~ 48 kg  (팩 수준이면 40~55 kg)   [출처]
```

**배낭 총중량 권장 상한이 체중의 20%(70 kg 성인 기준 14 kg)입니다.**
배터리만 30 kg인 장치는 **그 자체가 조난 원인**이 됩니다.

30일이면 9,360 Wh, 60~90 kg. 논의할 가치가 없습니다.

### 4.3 배터리 사양 권고

| 용량 | 대상 | Li-ion NMC 무게 | LiFePO4 무게 | 판정 |
|---:|---|---:|---:|---|
| 150 Wh | 7일 | 0.8~1.0 kg | 1.3~1.7 kg | 대회 시연에 충분 |
| **330 Wh** | **14일 (권고)** | **1.7~2.2 kg** | **2.8~3.7 kg** | **채택 권고** |
| 700 Wh | 30일 | 3.5~4.7 kg | 5.8~7.8 kg | 무게 부담 큼 |

**권고 구성**

| 항목 | 값 | 사유 |
|---|---|---|
| 화학 | **Li-ion NMC (18650/21700)** | 에너지 밀도 우선. 배낭 무게가 안전 요소 |
| 용량 | **330 Wh** (예: 11.1V 30Ah 또는 14.8V 22Ah) | §4.2 계산 |
| 보호 | **BMS 필수** (과충·과방·과전류·온도) | |
| **저온 특성** | **충전 하한 0°C 확인** | **Li-ion은 0°C 이하에서 충전하면 리튬 도금으로 영구 손상.** 겨울 산행 필수 고려 |
| 잔량 계측 | 쿨롱 카운터 (INA219/MAX17205 급) | 전압만으로는 부정확 |
| 항공 운송 | **100 Wh 초과 = 항공 반입 제한** | **330 Wh 단일 팩은 여객기 반입 불가.** 대회 이동에도 영향 |

> **항공 100 Wh 제한은 실무 함정입니다.**
> **100 Wh 미만 모듈 4개 분리형**으로 설계하면 이 문제와 고장 격리를 동시에 해결합니다.
> 심사위원이 "실제로 오지에 가려면 비행기를 타는데요?"라고 물을 수 있습니다.

## 5. 태양광 판정 — ⭕ 보조로만

### 5.1 실제 출력 `[출처]`

| 조건 | 정격 대비 실제 출력 |
|---|---|
| 최적 조건 (개활지, 정오, 직각) | 정격의 **50~60%** |
| 얇은 구름 | **50% 감소** |
| 짙은 흐림 | **정격의 10~20%** |
| **숲 캐노피 아래 / 산 그늘** | **80% 이상 감소** |

**실증 관측**: PCT(태평양 종주로, 사막·개활지) 종주자는 태양광을 들고 다니고,
**AT(애팔래치아, 삼림) 종주자는 보조배터리를 들고 다닙니다.** 숲에서는 태양광이 무의미하기 때문입니다.

### 5.2 계산 `[추정]`

```
20 W 접이식 패널, 개활지, 유효 일조 5시간
  20 W × 0.55 × 5 h ≈ 55 Wh/일   →  일 소요 18.9 Wh의 약 3배. 충분

같은 패널, 숲 캐노피 아래
  20 W × 0.55 × 0.2 × 5 h ≈ 11 Wh/일  →  일 소요의 58%. 부족
```

### 5.3 판정

| 항목 | 결론 |
|---|---|
| 태양광만으로 무한 운용 | **❌ 불가.** 지형·날씨 의존이 너무 큼 |
| 태양광 + 330 Wh 배터리 | **⭕ 권고.** 개활지에서 충전할 기회가 있으면 운용 기간이 2배 이상 |
| 패널 크기 | **20~28 W 접이식** (배낭 상단 부착형) |
| **필수 조건** | **MPPT 컨트롤러.** PWM은 저조도에서 손실이 큼 |
| **UI 요건** | 발전량을 **시안(계측값)** 으로 표시. **없으면 회색.** "충전 중"을 녹색으로 위조하지 말 것 |

## 6. 발전기 판정 — ❌ 넣지 마세요

| 방식 | 실제 출력 `[추정]` | 330 Wh 채우는 데 필요한 시간 | 판정 |
|---|---:|---:|---|
| **수동 크랭크** | 5~10 W (전력 소모하며 계속 돌릴 때) | **33~66시간 크랭크** | ❌ 논외 |
| 열전(TEG, 스토브 열) | 2~5 W | 66~165시간 취사 | ❌ 논외 |
| 소형 수력 | 5~15 W | 흐르는 물 옆에 고정 필요 | ❌ 범위 밖 |
| 풍력 | 변동 극심 | — | ❌ 범위 밖 |

**추가 문제**: 수동 크랭크는 **에너지를 쓰는 사람이 조난자 본인**입니다.
탈진·저체온 상태에서 33시간 크랭크는 생존 전략이 아니라 사망 촉진입니다.

**결론: 발전기는 넣지 마세요.** 무게와 복잡도만 늘고 전력 예산에 기여하지 않습니다.
심사위원이 "발전기는 왜 없나요"라 물으면 **위 표를 그대로 보여 주면 됩니다.** 오히려 가점 요인입니다.

## 7. STM32의 역할 변경 — 이 설계의 핵심

**기존**: 서랍 컨트롤러 (LED, 솔레노이드, ACK 센서)
**신규**: **상시 전원 관리자 + 센서 허브 + GNSS 로거**

```
        ┌──────────────────────────────────────┐
        │  배터리 330 Wh + BMS + 쿨롱 카운터   │
        └────────────────┬─────────────────────┘
                         │
        ┌────────────────▼─────────────────────┐
        │  STM32H7A3ZI-Q  — 항상 켜져 있음     │  0.25 ~ 0.4 W [재측정]
        │   · CO 센서 1 Hz 감시  ← 생명 안전   │
        │   · 온습도·기압 1/60 Hz              │
        │   · GNSS 자동 위치 로깅              │
        │   · 배터리 쿨롱 카운팅               │
        │   · 부저 · 진동 · LED 직접 구동      │
        │   · Jetson 전원 게이팅 (MOSFET)      │
        └────────────────┬─────────────────────┘
                         │ 필요할 때만 전원 인가
        ┌────────────────▼─────────────────────┐
        │  Jetson Xavier NX  — 기본 OFF        │  12 ~ 19 W
        │   · 지도 렌더링 · LLM · STT · TTS    │
        └──────────────────────────────────────┘
```

### 7.1 Jetson 기동 조건 (이것만)

```
1. 사용자가 물리 버튼을 누름
2. 사용자가 화면을 꺼냄 (홀 센서 / 자석 스위치)
3. STM32가 임계 초과를 감지 → 음성 안내가 필요할 때
      · 트레일 이탈 > 임계 거리
      · 잔여 일조 시간 < 소요 예상 시간
      · 기압 급강하
4. 예약 시각 (아침 브리핑)
```

### 7.2 STM32 단독으로 완결되어야 하는 것 (Jetson 없이)

```
· CO 경보            → 부저 + 진동 + 적색 LED
· 저온 경보          → 부저
· 배터리 임계 경보   → 부저
· 조난 신호 모드     → 호루라기/스트로브 6회/분 반복
· GPS 자동 위치 로깅 → 내장 플래시
```

> **2026-08-31 현재 구현**: CO **판정만** STM32 단독이고, 경보음(비프)과 음성 안내는 Jetson 스피커가 냅니다. 부저·진동·LED는 향후 적용 예정이라, 그 전까지 Jetson 전원이 꺼진 구간에는 소리가 나지 않습니다.

> **부팅에 15초 걸리는 경로에 사람 목숨을 걸면 안 됩니다.**
> CO 경보가 Jetson 기동을 기다리면, 자고 있는 사람은 그 사이에 죽습니다.

### 7.3 부팅 시간 — 반드시 측정할 것

| 항목 | 목표 | 상태 |
|---|---:|---|
| Jetson 콜드 부팅 → UI 표시 | ≤ 15 s | `[미검증]` |
| Jetson 콜드 부팅 → LLM 응답 가능 | ≤ 25 s | `[미검증]` |
| **대안: SC7 딥슬립 → 복귀** | **≤ 3 s** | `[미검증]` **우선 검토** |

**SC7 딥슬립(0.2 W)에서 복귀하는 게 완전 종료보다 훨씬 빠릅니다.**
14일 × 24h × 0.2W = 67 Wh로 예산 안에 들어옵니다.
**부팅 15초 vs 복귀 3초는 사용성에서 결정적 차이입니다. W1에 측정하세요.**

## 8. 요구 3.5에 대한 최종 답

| 요구 | 답 |
|---|---|
| **1. 발전기를 넣을지** | **넣지 마세요.** 수동 크랭크 1시간 = 5~10 Wh. 필요량의 4%. 무게·복잡도만 증가 |
| **2. 태양광을 이용할지** | **보조로 넣으세요.** 20~28W 접이식 + MPPT. 개활지에서만 유효하며, 숲에서는 80% 이상 감소. **주 전원으로 설계하면 안 됨** |
| **3. 큰 배터리 크기·용량** | **330 Wh (Li-ion NMC, 약 1.7~2.2 kg).** 단, **상시 구동이 아니라 듀티 사이클링 전제**입니다. 상시 구동으로 2주는 4,200 Wh · 30 kg으로 물리적으로 불가능합니다. **항공 운송 때문에 100 Wh 미만 4모듈 분리형을 권고합니다.** |
