## 0. 폼팩터 (첨부 이미지 기준)

| 항목 | 해석 |
|---|---|
| 본체 | 배낭 상단 외부에 장착된 방수 하드케이스. 무전기/배터리팩 크기 |
| 화면 | 7인치 LCD, **연장 케이블로 본체와 분리**. 배낭 측면 슬롯에 꽂아 두고 필요시 꺼냄 |
| 음성 | 골전도 또는 이어 스피커 — 화면을 못 볼 때의 주 출력 |
| 전원 | 본체 내부 배터리 + (선택) 외부 태양광 |
| 방수 | **IP65 이상 필수.** 비 맞는 게 예외가 아니라 기본 조건 |

**설계에 미치는 영향 3가지**
1. **케이스가 밀폐되면 Xavier NX가 열로 스로틀링됩니다.** → [07 §4](07_hardware_feasibility.md)
2. **화면은 대부분 꺼져 있습니다.** 음성이 1차 출력, 화면이 2차입니다. 기존 UI 전제와 반대입니다.
3. **연장 케이블 = 신호 무결성 문제.** LVDS/eDP는 장거리 안 갑니다. HDMI 또는 USB-C DP Alt Mode + 능동 케이블로 가야 합니다. `[미검증 — 실측 필요]`

## 3.1 통신 삭제 & GPS 강화 (오프라인 지도)

### 요구
- 길 찾기 / 현재 위치 정확 파악 / 오프라인 지도 실시간 표시 / 체크포인트 / 사전 다운로드 후 LLM 보조 탐색

### 설계

**(a) 측위**

| 항목 | 값 |
|---|---|
| 모듈 | **Seeed Grove GPS (Air530)** — 6계 GNSS(GPS/BeiDou/GLONASS/Galileo/QZSS/SBAS), UART/NMEA, u.FL 외장 안테나 동봉.<br>※ 초안의 NEO-M9N → MAX-M10S → Air530으로 2회 변경. 최종 근거는 **[10 §3.1](10_parts_selection_bom.md)** |
| 인터페이스 | UART → **STM32** (Jetson 아님. 이유는 [06](06_power_budget_battery.md)) |
| 실측 정확도 | 개활지 2~5 m / **밀림 캐노피 아래 1~12 m** `[출처]` |
| 최대 오차원 | **다중경로(multipath)** — 숲에서 가장 큰 오차원 |

> **UI 규칙**: 정확도(HDOP·위성 수)를 항상 같이 표시합니다.
> "±8 m"를 숨기고 점 하나만 찍으면 사용자가 정밀도를 오해합니다. 안전 계약 §5-4.

**(b) 오프라인 지도**

| 방식 | 용량 | 판정 |
|---|---|---|
| 래스터 타일 (MBTiles) | 베를린 z12–17 기준 **약 825 MB** `[출처]` | 렌더링 부하 낮음, 용량 큼 |
| **벡터 타일 (MBTiles/PMTiles)** | **같은 영역 약 35 MB** `[출처]` | **채택.** 24배 작고 확대 자유 |
| OsmAnd `.obf` | 중간 | 우리 렌더러와 통합 어려움 |

**용량 추정 `[추정]`**: 국립공원 1곳(50×50 km) 벡터 z8–16 → **50~150 MB**.
남한 전역 z8–15 → **1.5~3 GB**. NVMe에 여유 있음.

**(c) 길 찾기 — 안전 계약이 걸리는 지점**

```
[허용] 사전 다운로드한 트레일 그래프 위에서의 경로 탐색 (A*/Dijkstra)
       → 결정론적. 검증 가능. 소스는 OSM 트레일 데이터.

[허용] 현재 좌표 → 등록 체크포인트까지 방위·직선거리 (haversine)
       → 순수 삼각법.

[금지] LLM이 방위각·거리·"저쪽으로 가세요"를 생성하는 것.
[금지] 트레일 그래프가 없는 지역에서 오프트레일 경로를 제안하는 것.
       → "경로 데이터 없음" 회색 상태로 정직하게 표시.
```

**(d) 체크포인트**

| 종류 | 저장 시점 | 용도 |
|---|---|---|
| **베이스캠프** | 사용자 지정 | 귀환 기준점 |
| **텐트 앵커** | 취침 전 원터치 | 야간 복귀 ([03 D](03_beginner_risk_taxonomy.md)) |
| **수원** | 사용자 지정 | 재보급 계획 |
| **탈출점(bail-out)** | 루트 로드 시 자동 | 회귀 판단 계산의 목적지 |
| **자동 위치 로그** | **자동, 60초 간격** | Largay 유형 차단 |

**(e) "LLM 도움으로 좀 더 안전하게 탐색"의 정확한 의미**

이 문장이 위험합니다. 아래로 한정합니다.

| LLM이 하는 것 | LLM이 하지 않는 것 |
|---|---|
| 지도 엔진이 계산한 값을 **읽어 주기** ("탈출점까지 2.1 km, 도보 45분 예상") | 거리·방위 계산 |
| 사용자 질문을 라벨로 **분류** | 경로 선택 |
| 사전 등록된 루트 메모를 **요약** | 안 가 본 지형 판단 |
| 고정 카드 문장을 상황에 맞게 **다듬기** (2~4줄) | 새 절차 생성 |

### 판정
**기술적으로 전부 가능.** 4주 내 P0(a·b·d) 가능, (c) 길찾기는 트레일 그래프 준비가 병목.

## 3.2 수면 중 안전 — **"딱히 생각이 안 난다"에 대한 답**

[03 D](03_beginner_risk_taxonomy.md)에 근거가 있습니다. 여기서는 구현만 적습니다.

| # | 기능 | 부품 | 원가 | 구현 난이도 | 근거 |
|---|---|---|---|---|---|
| **1** | **일산화탄소 경보** | MQ-7 / ZE07-CO / MiCS-5524 | 5천~2만 원 | 낮음 | 미국 텐트 내 CO 사망 **연 30명** |
| **2** | **텐트 앵커 + 야간 복귀 유도** | 없음 (GPS 재활용) | 0원 | **매우 낮음 (3시간)** | Largay 유형 |
| **3** | **야간 감시 모드** | STM32 + 온습도(SHT40) + 기압(BMP390) | 1만 원 | 중간 | 저체온·기상 급변 |
| **4** | **취침 전 체크카드** | 없음 | 0원 | 매우 낮음 | 야영지 5대 위험 |
| 5 | 기상 급변 경보 (기압 급강하) | BMP390 재활용 | 0원 | 낮음 | Zambretti |
| 6 | 무동작 감시 (dead-man) | IMU | 3천 원 | 중간 | 낙상·의식 소실 |

**권고: 1 + 2 + 4를 P0로.** 셋 다 4주 안에 확실히 됩니다.

**야간 감시 모드 동작 정의**

```
22:00 ~ 06:00 (또는 사용자 지정)
  Jetson: 완전 종료 (전력 0)
  STM32:  상시 각성
    - CO      1초 주기 샘플링
    - 온·습도 60초 주기
    - 기압    60초 주기
    - GPS     OFF (텐트는 안 움직임)

  경보 조건 (OR):
    CO [주의] 35 ppm 3분 지속 또는 10분 내 +20 ppm 급상승
                         → 부저 약 + 진동 (Jetson 기동 불필요)
    CO [경보] 100 ppm 이상, 또는 UL 2034 곡선 도달
              (70 ppm/60분, 150 ppm/10분, 400 ppm/4분)
                         → 즉시 부저 최대 + 진동 + LED 적색 (Jetson 기동 불필요)
    텐트 내 기온 ≤ 2°C   → 부저 약 + Jetson 기동 → 음성 안내
    기압 3시간 −4 hPa 이상 하강 → Jetson 기동 → 음성 안내
```

> **2026-08-31 현재 구현**: CO **판정만** STM32 단독이고, 경보음(비프)과 음성 안내는 Jetson 스피커가 냅니다. 부저·진동·LED는 향후 적용 예정이라, 그 전까지 Jetson 전원이 꺼진 구간에는 소리가 나지 않습니다.

> **가정용 표준보다 의도적으로 공격적입니다.** UL 2034는 오경보를 줄이려고 **30 ppm 미만 경보를 금지**하고
> 70 ppm에서 60~240분을 기다립니다 `[출처]`. 텐트는 부피가 방의 1/10 수준이라 농도가 훨씬 빨리 오르고,
> **텐트 안에서 CO가 검출된다는 것 자체가 화기를 켜 놓은 오류 상황**입니다.
> 절대 농도와 **상승률**을 같이 봅니다.

> **CO 경보는 Jetson 없이 STM32 단독으로 완결되어야 합니다.**
> 부팅에 10초가 걸리는 경로에 사람 목숨을 걸면 안 됩니다.
> 이건 [06](06_power_budget_battery.md)의 전력 설계와도 정확히 일치합니다. **드물게 나오는 win-win입니다.**

### 판정
**가능하고, 이 작품에서 가장 설득력 있는 기능군입니다.**

## 3.3 온·습도 · 날씨 · 일출몰

### 요구
1. 현재 위치 기반 일출·일몰 시각 → 언제까지 자리를 잡아야 하는지
2. 날씨·온도 기반으로 어떻게 움직일지 LLM과 상담

### 설계

**(a) 일출·일몰 — 완전 결정론적, 네트워크 0**

| 항목 | 값 |
|---|---|
| 알고리즘 | **NOAA Solar Calculator (Jean Meeus, *Astronomical Algorithms*)** `[출처]` |
| 입력 | 위도, 경도, 날짜 **(그게 전부)** |
| 정확도 | **위도 ±72° 이내 분 단위** |
| 태양 고도 기준 | 일출·일몰 −0.833° / 시민박명 **−6°** / 항해박명 −12° / 천문박명 −18° |
| 연산량 | 무시 가능 (수십 μs) |

**핵심 파생 지표 — 이게 [01 §6] 차별화 후보 A의 실체입니다**

```
잔여_행동시간 = 시민박명_종료 − 현재시각
소요_예상     = 잔여거리(트레일 그래프) ÷ 최근30분_실측속도(GPS)
여유율        = 잔여_행동시간 / 소요_예상

여유율 ≥ 1.5  → 녹색  "여유 있음"
1.0 ~ 1.5     → 앰버  "지금 판단하세요"
< 1.0         → 적색  "지금 돌아서지 않으면 어두워집니다"
```

> **주의**: 숲·계곡은 시민박명보다 훨씬 일찍 어두워집니다.
> **지형 보정을 못 하므로 −6°가 아니라 −3°(일몰 후 약 15분)를 임계로 쓰는 편이 안전합니다.** `[추정]`
> 이건 보고서에 근거와 함께 적어야 합니다. 심사위원이 물어봅니다.

**(b) 기상 — 여기가 정직성 시험대**

인터넷이 없으므로 **예보를 받을 수 없습니다.** 할 수 있는 건 국지 추정뿐입니다.

| 방법 | 입력 | 출력 | 정직한 표기 |
|---|---|---|---|
| 실측 | SHT40 (온·습도), BMP390 (기압) | 현재값 | **녹색 (LIVE)** |
| **Zambretti 알고리즘** | 해면기압, 기압 변화 추세, 계절, 반구, 풍향 | 26개 예보 문장 중 1개, **12시간 전망** | **앰버 (추정)** |
| 정확도 | 문헌상 12시간 예보 **90~94%** (북반구) `[출처]` | — | **이 수치는 평지 기준. 산악에서 검증되지 않음** |

> **경고**: "90% 정확"을 그대로 화면에 쓰면 안 됩니다.
> Zambretti는 1920년대 슬라이드룰 기반이고, 산악 국지 기상은 훨씬 변덕스럽습니다.
> 화면에는 **"기압 추세 기반 추정"** 이라고만 쓰고, 정확도 수치는 보고서에만 씁니다.

**(c) LLM 기상 상담 — 허용 범위**

| 허용 | 금지 |
|---|---|
| "기온 6°C, 습도 92%, 기압 하강 중" 을 문장으로 읽어 주기 | 예보 생성 ("내일 비 옵니다") |
| 조건 조합 → **고정 카드** 선택 ("저체온 주의 카드") | 새 처치·행동 절차 생성 |
| 사용자 질문 분류 | 출발/철수 결정 |

### 판정
**(a)는 완전 가능하고 비용도 0입니다. 반드시 넣으세요.**
(b)는 센서 추가 필요, 4주 내 가능. **(c)는 안전 계약 준수 여부가 관건.**

**신규 UI 요건 4개**

1. **야외 시인성**: 실내용 250 nit 패널은 직사광선에서 안 보입니다.
   **최소 800 nit, 가능하면 1000 nit 이상** + 무광 처리. `[미검증 — 현 패널 사양 확인 필요]`
2. **글랜서블(glanceable) 계층**: 화면을 켜는 순간 **1초 안에** 읽혀야 할 4개 —
   `현재 좌표 상태` / `남은 일조 시간` / `배터리 잔여 일수` / `트레일 이탈 여부`.
3. **야간 모드**: 적색 단색 모드. 백색광은 암순응을 파괴하고 전력도 더 씁니다.
4. **젖은 손·장갑**: 정전식 터치는 물 묻으면 오작동합니다.
   **물리 버튼 3개(전원 / 체크포인트 저장 / 음성 질문)를 반드시 두세요.** 터치가 죽어도 P0 기능이 살아야 합니다.

### 판정
가능. 단 **패널 휘도**와 **연장 케이블 신호 무결성** 2개가 미검증 리스크입니다.
